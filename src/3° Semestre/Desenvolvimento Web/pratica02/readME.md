# 📊 KPIs para Loja de Varejo

## ✅ Principais Indicadores com Sugestões de Gráfico

1. [ ] **Receita mensal**  
   - *O que mede:* Total em vendas por mês  
   - *Gráfico ideal:* Gráfico de **linhas**

2. [ ] **Taxa de conversão de vendas**  
   - *O que mede:* % de visitantes que realizam compra  
   - *Gráfico ideal:* Gráfico de **barras** ou **colunas**

3. [ ] **Nível de satisfação do cliente (NPS)**  
   - *O que mede:* Avaliação da experiência geral do cliente  
   - *Gráfico ideal:* **Medidor (gauge)** ou **barras**

4. [ ] **Ticket médio por venda**  
   - *O que mede:* Valor médio gasto por cliente  
   - *Gráfico ideal:* **Linhas** ou **barras**

5. [ ] **Volume de vendas por categoria de produto**  
   - *O que mede:* Quais produtos ou categorias vendem mais  
   - *Gráfico ideal:* **Pizza** ou **barras horizontais**

6. [ ] **Custo de aquisição de cliente (CAC)**  
   - *O que mede:* Custo médio para conquistar um cliente  
   - *Gráfico ideal:* **Linhas**

7. [ ] **Taxa de retorno de produtos**  
   - *O que mede:* % de devoluções  
   - *Gráfico ideal:* **Barras** ou **linhas**

8. [ ] **Margem de lucro bruta**  
   - *O que mede:* Diferença entre receita e custo dos produtos vendidos  
   - *Gráfico ideal:* **Área** ou **colunas**

9. [ ] **Estoque médio por período**  
   - *O que mede:* Quantidade média de produtos em estoque  
   - *Gráfico ideal:* **Linhas**

10. [ ] **Número de clientes recorrentes**  
    - *O que mede:* Clientes que retornam para comprar novamente  
    - *Gráfico ideal:* **Barras empilhadas** ou **linhas**
